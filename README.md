# Matrix AI

Cybersecurity chat platform (Matrix Sentinel).

## Features

- Phone-responsive chat dashboard
- **All chats** listed in the sidebar nav
- **All histories** view
- Chat titles generated from the conversation theme
- Screenshot / file attach **inside the chat** (no extra page)
- Sentinel model: answers anything about cybersecurity (defensive; no exploits)
- Admin panel (`admin@matrix.ai` / `admin123`)
  - View all chats
  - Manage users, ban / unban, promote / demote
  - Add quizzes
  - Certificate HTML templates (`{{name}}` `{{course}}` `{{date}}` `{{score}}`)

## Run

```bash
npm install
npm run dev
```

Open the preview. Register a user or sign in as admin.
